Gde se čuvaju podaci — važno

      
    
        
  • Podaci se čuvaju samo lokalno u pregledaču ovog uređaja. Nema registracije, naloga ni servera.
    • 
        
  • Ne sinhronizuju se između uređaja. Ako promenite telefon ili računar, morate preneti JSON kopiju.
    • 
        
  • Privatno pregledanje, brisanje podataka sajtova / istorije Safari-ja ili reset telefona mogu obrisati arhivu. Safari može obrisati podatke sajtova koje dugo niste otvarali.
    • 
        
  • Zato redovno izvezite JSON kopiju i sačuvajte je u Files / iCloud Drive.
    • 
        
  • Za pouzdano korišćenje na iPhone-u: otvorite aplikaciju sa web adrese (besplatno hostovanje, npr. GitHub Pages ili Cloudflare Pages) i izaberite Safari → Podeli → „Dodaj na početni ekran“. HTML fajl otvoren direktno iz aplikacije Files često ne omogućava trajno čuvanje podataka ni kameru.
